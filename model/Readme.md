## Pre-built Models
Following pre-built models are available. User need to download these in this directory and adjust the model name in [source](src/qawwali.py)

- First version of model, with high false positive [download](https://drive.google.com/file/d/1aXA3NvXf9SIYCUDM9AnNxRXUeGATcLVz/view?usp=sharing)
- Improved version of mode, with lower false positive at the cost of slighly increased false negative [download](https://drive.google.com/file/d/1EHf2SOf9GbdeSGCgOsH1Y0BpHgqY1WW_/view?usp=sharing)
- Standalone inference without requiring a valid model object [download](https://drive.google.com/file/d/12HOk5H8tCuhtiKweG_pIECDYAwQ4c_Vr/view?usp=sharing)
